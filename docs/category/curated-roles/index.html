Curated Roles

Preconfigured roles for common use cases. Each has detailed instructions on how to include them into your use case

This currated role can be used to deploy EasyTrade demo application on the ACE-Box.

📄️ dt-access-token

This role creates DT access tokens on the user's behalf. In order to do so, a initial token needs to be provided that has the permissions (apiTokens.read and apiTokens.write) to create other API tokens. Each role that requires access to the DT API is responsible for managing its own access token and scopes.

📄️ dt-activegate-classic

This currated role can be used to deploy Dynatrace ActiveGate on the ACE-Box VM.

📄️ dt-edge-connect

This currated role can be used to deploy the Dynatrace Edge Connect component in your k8s cluster.

📄️ dt-oauth-token

This role allows you to create an oauth token on demand. After including the role, a newly created token can be used as variable dtoauthaccess_token.

📄️ dt-oneagent-classic

This currated role can be used to deploy the Dynatrace OneAgent on the host.

📄️ dt-operator

This currated role deploys the Dynatrace Operator to monitor your Kubernetes cluster. Dynatrace provides different deployment options: application-only + k8s-api, cloudNativeFullStack, and classicFullStack. Notice that the prerequisites for each are different
